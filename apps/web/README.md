# Veilbound web

This is the intentionally small first PWA shell.

The first application milestone is a fast, offline-capable reference reader. It should eventually consume canonical rules/world/content rather than duplicate them inside UI code.

## First milestone

- installable PWA;
- responsive reference shell;
- offline shell cache;
- rules/world/content navigation;
- search;
- stable cross-links;
- bookmarks/favorites;
- player/GM visibility handling;
- optional dice roller.

Character building, campaign state, encounters, realtime synchronization, and VTT features are deliberately deferred.
