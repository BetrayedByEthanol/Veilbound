# Documentation

The documentation tree separates **design history** from **current game truth**.

## Structure

- `design/` — audits, decisions, balance notes, alternatives, migration notes.
- `rules/` — canonical core rules organized for fast lookup.
- `world/` — canonical lore and world reference.

## Rules organization target

The initial target structure is:

1. Overview and principles
2. Core resolution
3. Character creation
4. Abilities and training
5. Non-combat play
6. Combat
7. Vigor, wounds, dying and death
8. Veil and magic
9. Archetypes
10. Focus
11. Advancement
12. Equipment
13. Crafting
14. Travel and exploration
15. GM rules

Create the specific files as those systems are promoted from design/audit material into canonical rules.
