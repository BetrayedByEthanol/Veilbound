# Design records

This directory holds material used to **design** Veilbound rather than material players should treat as the current rules.

Suggested subareas:

- `audits/`
- `decisions/`
- `balance/`
- `experiments/`
- `migration/`

The current Core Rules Audit should eventually live here as a tracked design/backlog document. Resolved items should be reflected in `docs/rules/` or `content/`.
