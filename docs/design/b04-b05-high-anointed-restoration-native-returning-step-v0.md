## Native source-bound action and resource contract

The [High Anointed native adapter](../../scripts/b05_high_anointed_native_returning_step_v0.py) is installed only with exactly sourced **AH High Life/Restoration** L1–3, a true native G1 map and G4 injury state. The character's source file is independently SHA-256 bound, the real G0 actor has exact 30/36/42 Turn AP and 20-AP High Projection, 12 Max HP, 12/24/36 Vigor and 6/12/18 VP. The adapter separately retains the finite **2-Destiny starting account** from [canonical Anointed v0](../rules/08-archetypes/anointed-signature-authority-l1-3-v0.md), not a fabricated G0 `Actor.destiny` field.

`project(target, visible=True, unopposed=True, lesser=...)` may run **only on an actually ready, positive-HP AH own turn** with a surviving 20-AP G0 Projection budget. The proposed target must already be living with **positive but missing HP**, and for a baseline conversion have their own Vigor; for the **1-Destiny Lesser Spare the Reserve**, it may have **0 Vigor**. Exactly one **20-AP G0 `action_committed`** record pays **20 AP** for each attempted High Signature Projection, **0 VP**. The G4 packet must bind the exact fresh action index, native caster source, current turn and real recipient state, rather than accepting a supplied hypothetical action or mutable receipt. G4 independently recomputes `H=min(2, missing HP, available recipient Vigor)` (baseline), or `H=min(2, missing HP)` (Lesser), and changes the **real recipient's HP and Vigor ledger**. No wound progress, Dying rescue, extra Regeneration Step, VP refund or duplicate G4 payment occurs. The adapter's separate source referee commits one finite Destiny only on successful Lesser application, and the G0/G4 ledger records the source action index, HP/Vigor before and after, Destiny cost and SHA.

The G1 current grid provides a **0–3 square** outward target distance at L1, **0–4** at L2–3. Native geometry revalidates the living target's actual occupied position and solid-wall ray, rejecting blocked interiors, unadjudicated corner openings and intervening creatures where magical-path authority is unresolved. Current visibility is explicitly declared as a scene fact, **not independently certified visual perception**. A returned `visible=True` cannot pierce a real wall. The caster can also target self at zero distance.

**Beneficial Intrusion boundary:** Only an **explicit genuinely unopposed** target is currently supported. A conscious or still-operative prior refusal requires the separate **+8 Intrusion Barrier** and valid Direct Veil contest, which this adapter deliberately rejects as `UnresolvedDecision`; it does not pretend a caller-supplied `intrusion_succeeded=True` authenticates resistance. Source-declared G4 HP-restoration prohibitions and a provided live restoration check are evaluated before and after payment; a current HP block rejects the packet. Merely blocking *external Vigor restoration* does not prohibit the recipient spending **their own** Vigor. This is a source-selected unwarded/unopposed slice; it is **not** all-condition Intrusion, darkness, anti-magic, three-dimensional targeting or interruption coverage.
