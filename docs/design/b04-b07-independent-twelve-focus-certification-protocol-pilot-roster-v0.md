## Exactly what "independent full Focus certification" means

A reviewer is **separate from the submitted record's implementer/author**, identifies the source version and examines primary evidence, rather than approving a character's own `verify()`, a synthetic matrix's scenario label or a player-provided review string. Each requirement below is **mandatory for the pairing's L1, L2 and L3 selected character**. A requirement can be substantiated by multiple compatible sessions; each report must distinguish a *real observed human choice* from a *deterministic countercase/procedural replay*. Both are valuable, but not interchangeable.

| Required domain | Reviewable evidence | Reject / return for work when |
|---|---|---|
| **C1 — Creation and provenance** | Exact authored source path and SHA, distinct player character/variant, 28-point Abilities where applicable, legal 150-sp equipment, 2 Weapon Development points (including saved balance), Learned Discipline family/level budget, known/prepared/linked/bonded access; HP/Vigor/VP and Focus-specific AP/Guard/Tempo at **each** level | Missing legal sheet, forged price/rank, source hash mismatch, proxy treated as complete, invented access/extra gear |
| **C2 — Advancement and conservation** | Independent L1→2→3 before/after snapshot; earned **vs selected vs saved** Talents, Training and repertoire; ability prerequisites/current levels; AP/VP and refund/commitment accounting. Preserve [merged #182](https://github.com/BetrayedByEthanol/Veilbound/pull/182) High Priest, Medium Gifted and Low Scholar ledgers | Extra/borrowed Talent, free respec, unearned L3 discount, magical ability acquired only because a tier ceiling rose, fictitious free refill |
| **C3 — Actual combat choice** | **Player-selected** legal paid primary/off-turn actions in meaningful opposing encounters, a different genuine alternative considered, precise AP/VP/Guard/MP/Reaction, attacker/defender source, rolls, result, wound and aftermath ledger | Fixed-seed policy only, outcome without provenance, free Ward/Rite/Signature/Step, no genuine opponent or meaningful decision |
| **C4 — Actual noncombat choice** | One actual source-legal exploration/social/investigation/knowledge/field utility decision **at each level**, alternatives considered, GM adjudication, time/hazard/material consequences | Only combat witnesses, invented GM ruling, description with no mechanical action, unauthored Aspect effect |
| **C5 — Negative/counterplay and limits** | Source-bound rejection, opportunity cost, insufficiency, target/geometry, VP/hand/access or opponent response countercase for the defining Focus mechanic; explain observed weaknesses or why no event occurred | Always succeeds, untested unavailable action, duplicate G4 Step/Pulse, unauthorized reaction/refund, unlimited recovery |
| **C6 — External review and session continuity** | Named/attributable independent reviewer reference plus actual raw logs/notes, session IDs/time/order, GM observation reference, adjudication of consent and contingent rules, provenance and source/event references; calibration includes outcomes and *denominators* | Reviewer equals author or no verifiable provenance; copied/fabricated attestations; limited fixture treated as representative whole fight |
| **C7 — Real milestones** | For each participating character, two distinct group-story GM-recognized event IDs, L1→L2 then L2→L3, explicit sheet/result review and event time among actual sessions | Automatic XP, victory/rest/Birth Mission event implies a level, reused milestone, skipped level or phantom refill |

**Graduation rule:** All **C1–C7** obligations are reviewed and accepted per pairing, including meaningful level-specific combat and noncombat alternatives, for one **complete** source-legal character line. Extra variants improve calibration but never increase the 12-pairing denominator. A reviewer may record **blocked**, **insufficient**, **requires implementation**, **ready for external review**, or **accepted after actual verified play**, with issue references and provenance; only separately authorized gate adjudication may change any global certification count. This PR creates no `accepted` or `certified` outputs. A candidate with all filled fields still has **zero independently certified Focuses**.

## Evidence artifact contract and non-certifying CLI

The CLI provides **source provenance** and a **template**, not authority to certify. Commands from the repository root:

```bash
python -m scripts.b04_b07_twelve_focus_certification_protocol_v0 --roster > pilot-roster.json
python -m scripts.b04_b07_twelve_focus_certification_protocol_v0 --template 'Priest/Low' > priest-low-blank.json
# Only after real observations: fill all source and external evidence references.
python -m scripts.b04_b07_twelve_focus_certification_protocol_v0 --check actual-candidate.json
```

`--roster` reports **12 pairings, 13 structural variants, 39 audited structural snapshots** (13 × 3), but only **36 pairing × level acceptance slots** (12 × 3). These are different denominators. It includes exact independent-audit source SHA-256 records, specific identity/required Focus choices, structural issues and an explicit **false** certification flag. It does not invent an external reviewer or human session.

`--template` returns a **blank** form per pairing: immutable version/pairing/source fingerprints, separate author/reviewer/review-file reference fields, **three** ordered L1–3 evidence entries and **two** separately identified, GM-declared chronological level-up claims. Each level demands an authentic source sheet reference, *separately reviewed* purchase ledger, combat action/alternative/consequence/countercase, noncombat action/alternative/consequence/countercase, paid source ledger and actual GM observation reference. Blank forms do **not** pass `--check`; neither a signature-like string nor a hash establishes external identity.

`--check` is **only syntactic intake preflight**. It refuses mismatched source fingerprints, unknown Focuses, duplicate/missing level/GM event refs, identical author/reviewer strings, unsupported fields, forged certification/exit flags and incomplete meaningful-choice categories. It still **cannot authenticate** independent reviewers, players/GM, actual encounter traces, willingness/Intrusion or milestone events. A complete but dishonest form can pass structure validation: its result remains `CANDIDATE_UNVERIFIED`, **0 externally verified sessions, false full-certification and 0 accepted MVP exits**. Human review must independently read raw evidence from external participants and compare original source/event receipts.

The existing [nine Anointed Focus × level evidence intake](b04-b05-anointed-field-pilot-evidence-v0.md) is a **subset with more detailed Mission/consent capture**. Cross-reference matching original Anointed session IDs/digests without treating either form's claims as independently validated or manufacturing nine extra Focus certificates.

## Actual work and stop/go

1. **Before play:** independently review all required L1 sheets and L2/L3 proposed changes, explicit played character IDs, current authored content, affordable action choices and representative scenario maps. Identify outstanding genuine rule/implementation gaps as **conditional** blockers with a named scene, not new G stages.
2. **During the 3–5-session adventure:** collect authentic player choices, meaningful considered alternatives, raw native/GM receipts, consequences, G4.2 time and recovery, wound/withdrawal outcomes, and actual distinct L2/L3 GM award events. An observation may legitimately show a player *declining* a skill or spell; it may not be converted into a fictional success.
3. **After each scene and level:** independent reviewer compares raw source, choice, action/cost ledger, GM judgement and challenge outcome; records flaws for the correct B04/B05/B06/B07 owner; repeat source-paid scenes when necessary. A deterministic negative fixture may support **C5**, not replace **C3/C4** live decision evidence.
4. **At acceptance:** adjudicate **each pairing separately**, then decide the six global Create/Act/Resolve/Advance/Challenge/Observe gates against actual reviewed evidence. No automated transition from `CANDIDATE_UNVERIFIED` exists. One accepted pairing would still not close the 12/12 Create requirement or six strict gates.

**Next coherent delivery after this protocol:** source/legal evidence packs and the first independently reviewable real-play character/scene record per Focus (or a suitable pilot encounter and noncombat package to produce them), without treating mock forms as real play. Arrange participant/GM/reviewer identities outside this repository; no personal identity or confidential session record is embedded in the repo by this PR.
