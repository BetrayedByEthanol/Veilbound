# Archetypes

Veilbound has four base Archetypes:

- [Priest](priest.md)
- [Scholar](scholar.md)
- [Gifted](gifted.md)
- [Anointed](anointed.md)

See [Archetype Identities](archetype-identities.md) for the concise cross-archetype comparison and access model.

Focus is a separate axis. See [Focus: Veil Expression](../09-focus/focus.md).

## Foundation status

The level 1–5 base architecture for all twelve Archetype/Focus combinations has passed the v34 foundation audit.

The individual Archetype files promote that foundation while preserving unresolved calibration boundaries rather than inventing missing values:

- repertoire/preparation counts;
- several VP/Destiny surcharges;
- Aspect-specific expression catalogues;
- final persistent-effect numerical budgets;
- later specialization/mastery mechanics.

The next documentation stage should split out highly reusable subsystems—such as Priest Pillar Accord/Miracle Petition, Gifted emotion rules, and Anointed Mission/Authority—into structured content or dedicated reference pages only where that improves lookup without creating duplicated sources of truth.
