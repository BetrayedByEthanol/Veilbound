# Archetypes

Veilbound has four base Archetypes:

- [Priest](archetype-identities.md#priest)
- [Scholar](archetype-identities.md#scholar)
- [Gifted](archetype-identities.md#gifted)
- [Anointed](archetype-identities.md#anointed)

See [Archetype Identities](archetype-identities.md) for the canonical shared access model and distinctions.

Focus is a separate axis. See [Focus: Veil Expression](../09-focus/focus.md).

The detailed level 1–5 foundations for each Archetype/Focus combination remain in staged migration from the Core Rules Audit and should be promoted without inventing missing calibration values.
