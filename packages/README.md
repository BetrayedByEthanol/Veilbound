# Shared packages

Planned reusable code lives here rather than being embedded directly in the web UI.

Initial package boundaries:

- `rules-engine/` — deterministic mechanical calculations and rule helpers;
- `content-loader/` — loading, validation, indexing, references, visibility filtering;
- `shared-types/` — shared software-facing types/contracts.

These remain placeholders until the canonical schemas/content are mature enough to justify implementation.
